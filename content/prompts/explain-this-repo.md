# Explain this repository

Give a newcomer a working mental model of this repository, cheaply.

1. Read the README and the top-level file list. Do not open every file.
2. Find the entry points (main modules, CLI, server start, package manifest scripts) and how
   to build, test and run the project.
3. Trace one typical request or command through the code, reading only the lines needed.

Answer in at most 40 lines:
- What it does, in two sentences.
- How to install, run and test it (exact commands).
- The main directories and what each is for.
- The path of one typical request or command through the code.
- Anything surprising: conventions, generated code, sharp edges.

Save durable facts about this project with `mem_add` (scope "project").
