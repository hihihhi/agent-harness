# Plan this task

Before writing any code, produce a short plan for the task described below.

1. Restate the goal in one sentence, and "done" as a command that will pass or fail.
2. Search memory and lessons for the task's keywords; note anything relevant.
3. List what you need to know that you do not know yet, and find it (search, read the needed
   lines only). Ask the human only about real decisions.
4. Break the work into 3 to 7 steps. For each: what changes, which files, and how it is checked.
5. Name the risks (data loss, long runs, shared resources) and how each step avoids them.
6. Save the plan with `state_save`, then start on step 1.
