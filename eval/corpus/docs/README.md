# Lumen platform documentation

SYNTHETIC. Lumen is a made-up batch-compute platform, and these pages exist only to give the
agent-harness eval something to retrieve from. Nothing here describes a real system.

## Pages

- `overview.md`: the cluster and who runs it
- `storage.md`: where files go and how long they stay
- `jobs.md`: running a job, queues and limits
- `runbook.md`: what to do when a job fails
- `policies.md`: quotas, support hours, data restores
- `data.md`: the orders extract in `data/orders.csv`
